# 🏡 한달살이 — 번아웃 2030 × 인구감소지역 AI 매칭 (시연용 프로토타입)

쉼이 필요한 2030에게 한 달 살기를 '처방'하고, 인구감소지역에는 '생활인구'를 연결합니다.

## 실행 방법

```bash
npm install     # 처음 한 번만
npm run dev     # http://localhost:5173 에서 확인 (AI 없이 '기본 분석 모드'로 동작)
```

AI까지 내 컴퓨터에서 확인하려면 `.env.local`에 키를 넣고 `npx vercel dev`로 실행합니다.

## 화면

| 주소 | 화면 |
|---|---|
| `/` | 메인: 후킹 문구, 왜 만들었나(인포그래픽), 기존 서비스와의 차이, 기대효과·카운터 |
| `/diagnosis` | 1분 진단 (객관식 8문항 + 한 줄 서술) |
| `/prescription` | AI 처방전 (유형, 지역, 정부 지원, 생활인구, AI 판단 근거, 이미지 저장) |
| `/map`, `/region/:id` | 지도, 지역 상세 |
| `/community` | 처방 후기 |
| `/gov` | 지자체용 데모: 공고문 → 표 추출 |

## AI 구조 (시연 중 멈추지 않게)

1. 지역 순위와 점수는 **항상 규칙으로 계산**합니다 (`src/utils/matching.js`).
   최종 점수 = 취향 × 0.5 + 자격 조건 × 0.3 + 지역 필요도 × 0.2
2. AI(`/api/prescribe`)는 한 줄 서술을 읽어 **유형 판단과 처방 문장**을 씁니다.
3. AI가 실패하거나 20초가 넘으면 자동으로 **기본 분석 모드**(템플릿 문장)로 바뀝니다.
4. 공고문 추출(`/api/extract-policy`)도 실패하면 정규식 기반 추출로 바뀝니다.

## API 키 설정

1. https://platform.claude.com 가입 → Billing에서 크레딧 충전 → API Keys → Create Key
2. **Vercel**: 프로젝트 → Settings → Environment Variables → `ANTHROPIC_API_KEY` 추가 → Redeploy
3. **내 컴퓨터(선택)**: `.env.example`을 복사해 `.env.local`로 저장하고 키 입력

⚠️ 변수 이름에 `VITE_`를 붙이지 마세요. 웹페이지에 키가 노출됩니다.
모델은 환경변수 `CLAUDE_MODEL`로 바꿀 수 있습니다 (기본값 `claude-opus-5-5`).

## 데이터 교체

| 샘플 파일 | 교체할 공공데이터 |
|---|---|
| `regions.json` → `population` | 한국고용정보원 소멸위험지수, 행안부 인구감소지역·생활인구 통계 |
| `spending.json` | 한국관광 데이터랩 관광 소비 지출 통계 |
